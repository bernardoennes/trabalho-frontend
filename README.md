# 🍕 Trabalho FrontEnd - Serrana Pizzaria
  O codigo presente nesse repositorio é um codigo simulando o site de uma pizzaria, mostrando cardapio com um sistema de carrinho, contatos e ate com uma sistema de perfil linkado ao MockAPI, para utilizar, apenas clique no site na descrição ao lado para ver, Este projeto fez parte da Residencia em TIC / Software 2025.1 do Serratec.
